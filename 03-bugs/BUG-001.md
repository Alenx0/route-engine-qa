# BUG-001: El comando de setup para crear carpetas falla en PowerShell

- **Fecha:** 2026-11-02
- **Módulo:** Documentación del repositorio QA (instrucciones de setup)
- **Severidad:** Baja
- **Prioridad:** Media
- **Entorno:** Windows, PowerShell, VS Code

## Precondiciones
- Terminal de VS Code abierta en la carpeta del repositorio, usando PowerShell.

## Pasos para reproducir
1. Pegar el comando: mkdir 01-plan-de-pruebas 02-casos-de-prueba 03-bugs
2. Presionar Enter.

## Resultado esperado
Se crean las carpetas indicadas.

## Resultado obtenido
Error: "No se encuentra ningún parámetro de posición que acepte el argumento '02-casos-de-prueba'" (PositionalParameterNotFound). No se crea ninguna carpeta.

## Evidencia
Mensaje de error en la terminal de VS Code.

## Notas
- Causa: en PowerShell, mkdir acepta una sola carpeta por comando. En CMD sí acepta varias.
- La instrucción asumía un entorno distinto al real del usuario.
- Corrección aplicada: usar un bucle de PowerShell: "carpeta1","carpeta2" | ForEach-Object { mkdir $_ }
- Estado: corregido y verificado con el comando alternativo.
